# Examination-finding assets

Cases reference these files by path relative to this folder: `finding.sound` and `finding.image` on
exam findings, `result.image` and `result.ecg` on investigation results (for example
`"sound": "sounds/heart-normal.wav"`). The student app loads them from `/assets/<path>`. Sounds play
with `new Audio()`, and images and ECGs are shown with `<img>`.

> **Every file here is a procedural PLACEHOLDER.** They are generated by code. They are not
> recordings or radiographs. The PRD says to use licensed medical sound and image libraries and to
> show the text finding where an asset is missing. Use these files only until licensed assets arrive.
> Every file is marked `"placeholder": true` in `manifest.json`.

## Files

| Path | Kind | What it is |
| --- | --- | --- |
| `sounds/heart-normal.wav` | sound | S1/S2 "lub-dub" at 80 bpm, no added sounds. 12 beats (9 s). |
| `sounds/heart-murmur-systolic.wav` | sound | Same heart sounds plus a crescendo–decrescendo (ejection) systolic murmur made from filtered noise between S1 and S2. |
| `sounds/lung-normal.wav` | sound | Vesicular breath sounds at 15/min: band-limited noise, with inspiration louder and longer than the short, soft expiration. 2 breaths (8 s). |
| `sounds/lung-wheeze.wav` | sound | Breath sounds with a prolonged expiration and a polyphonic musical expiratory wheeze (~400–750 Hz). |
| `sounds/lung-crackles.wav` | sound | Breath sounds plus fine, late-inspiratory crackles (short clicks). |
| `sounds/bowel-normal.wav` | sound | Intermittent bubbling gurgles over a quiet background (10 s). |
| `ecg/normal-sinus.svg` | ecg | Normal sinus rhythm, ~72 bpm. |
| `ecg/inferior-stemi.svg` | ecg | Sinus ~98 bpm. ST elevation in II, III and aVF (III > II), with reciprocal ST depression in I and aVL. |
| `ecg/anterior-stemi.svg` | ecg | Sinus ~88 bpm. ST elevation and hyperacute T waves in V1–V4. |
| `ecg/atrial-fibrillation.svg` | ecg | Irregularly irregular rhythm at ~110 bpm, no P waves, fibrillatory baseline. |
| `ecg/sinus-tachycardia.svg` | ecg | Sinus rhythm, ~125 bpm. |
| `images/cxr-normal.svg` | image | A stylised chest outline that stands in for a normal PA chest X-ray. It is labelled "Placeholder — replace with licensed image". |
| `images/cxr-placeholder.svg` | image | A generic, dimmed "image not available" chest placeholder. |
| `manifest.json` | — | Generated list of every asset with `path`, `kind`, `description`, `depicts` and `placeholder: true`. |
| `previews/*.png` | — | PNG renders of the SVGs, for review only. Cases do not reference them. |

Technical details:

- **Sounds:** 16-bit mono PCM WAV at 22.05 kHz, peak-normalised to 0.85 full scale, each under 450 KB.
  Every file is a whole number of cardiac or respiratory cycles. Events wrap around the end of the
  buffer, so the files loop seamlessly with `audio.loop = true`.
- **ECGs:** standard 12-lead layout in 3 rows × 4 columns (I aVR V1 V4 / II aVL V2 V5 / III aVF V3 V6),
  2.5 s per lead, taken from one simultaneous 10 s acquisition. Below that is a 10 s lead II rhythm
  strip. Paper speed is 25 mm/s and gain is 10 mm/mV, with a 1 mV calibration pulse on each row. SVG
  user units are millimetres on 1 mm / 5 mm grid paper. The header deliberately shows **no
  interpretation**, because students have to read the tracing. The interpretation is in
  `manifest.json` (`depicts`) for case authors only.

## Regenerating

From the repo root (Node 22, no extra dependencies):

```sh
npx tsx scripts/generate-assets.ts            # writes sounds/, ecg/, images/, manifest.json
npx tsx scripts/verify-assets.ts              # checks the WAV headers/levels, SVG well-formedness, ECG lead labels, manifest and case references
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npx tsx scripts/render-asset-previews.ts   # optional PNG previews
```

The output is deterministic (seeded PRNG), so re-running the generator produces byte-identical
files. Code layout:

- `scripts/audio/` holds the DSP helpers, the WAV encoder/decoder and the sound synthesisers.
- `scripts/ecg/model.ts` is a parametric beat model. Each lead has P/Q/R/S/T amplitudes and an ST
  offset. You can also set the heart rate, the PR interval and whether the rhythm is sinus or AF.
  Only I and II are specified; the other limb leads are derived through Einthoven/Goldberger. Presets
  live in `PRESETS`.
- `scripts/ecg/svg.ts` renders the model on ECG paper.
- `scripts/images/cxr.ts` draws the schematic chest placeholder.

To add an ECG, add an entry to `PRESETS` in `scripts/ecg/model.ts` and re-run the generator.

## Replacing with licensed assets

1. Get the licensed file and record its source and licence (for example in a `LICENSES` section of
   this README or a sidecar file).
2. **Keep the same path** if the format matches (`.wav` for `.wav`, `.svg` for `.svg`). No case
   changes are needed. If the format differs (for example a licensed `ecg/inferior-stemi.png` or
   `sounds/heart-normal.mp3`), add the new file and update the `sound`/`image`/`ecg` paths in the
   affected `content/cases/*.json`, then run `npm run validate-cases`.
3. In `manifest.json`, set `placeholder` to `false` for that entry and update `description`. Then
   remove that asset from `scripts/generate-assets.ts`, or exclude it there, so a regeneration
   cannot overwrite the licensed file.
4. Run `npx tsx scripts/verify-assets.ts`.
